# LCD32Encoder

Resonite向けに1bitモノクロ・5bitの32段階明度／固定32色の画像・文字・アニメーションをUTF-16 code unit列へ変換するWebアプリです。32×32パネルの横・縦の枚数を指定し、96×32などの配置を作れます。全パネル・全フレームを1本の文字列にまとめて出力します。

**公開サイト：[LCD32 Encoder](https://guhehep.github.io/LCD32Encoder/)**

GitHub Pagesで公開しています。`main` ブランチのルートを公開元とし、pushするとサイトが更新されます。`.nojekyll` によりHTMLをそのまま配信します。

## 実行

`index.html` をブラウザで開くだけで動作します。外部ライブラリ、ビルド、APIキーは不要です。

クラウド開発環境でHTTP経由の動作確認をする場合は、リポジトリのルートで以下を実行します。

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

ブラウザから `http://localhost:8000` を開きます。

## サイズとパネル配置

キャンバスのサイズから定番の配置を選ぶか、「パネルの枚数で指定」を開いて横・縦の枚数を入力し「配置を適用」を押します。横・縦はそれぞれ1〜8枚、合計16枚までです。サイズの表記は**幅×高さ**で、各辺は32の倍数になります。たとえば横3枚・縦1枚は96×32、横3枚・縦2枚は96×64です。

画像読込・描画・文字・サンプル・全フレームが選択サイズに対応します。画像は選択サイズに合わせて変換し、サンプルと静止文字は縦横比を保って中央に配置します。サイズ変更は既存の絵を左上に保持し、範囲外にドットがある場合は切り抜き前に確認します。縦2枚から横2枚への変更も同じ扱いです。

正面から見た配置と、出力全体を `|` で分割したときの順序は次のとおりです。各要素には、そのパネルの全フレームが入ります。表の長さは静止画（1フレーム）の場合です。

| サイズ | 配置 | 分割後の順序（0始まり） | 1フレームのUTF-16単位数 |
| --- | --- | --- | ---: |
| 32×32 | 1枚 | 0: 全体 | 69 |
| 32×64 | 縦2枚 | 0: 上、1: 下 | 139 |
| 64×32 | 横2枚 | 0: 左、1: 右 | 139 |
| 64×64 | 2×2の4枚 | 0: 左上、1: 右上、2: 左下、3: 右下 | 279 |
| 96×32 | 横3枚 | 0: 左、1: 中央、2: 右 | 209 |
| 32×96 | 縦3枚 | 0: 上、1: 中央、2: 下 | 209 |
| 96×64 | 横3×縦2枚 | 0〜2: 上段左から、3〜5: 下段左から | 419 |
| 128×32 | 横4枚 | 0〜3: 左から順に | 279 |

パネルの並び順は**左上から右へ、次に下の段へ**です。横の枚数をCとすると、0始まりのパネル位置は `行 × C + 列` です。縦2枚は `上|下`、横3枚は `左|中央|右`、2×2枚は `左上|右上|左下|右下` になります。`|` はSafeデータの範囲（U+3000–U+AFFF）に含まれないため、データと区別できます。各パネル内は従来のrow-major順・Safe形式で、最後の11bitの0埋めも各パネルに入ります。回転・反転はしません。

アニメーションは**パネルごとに全フレームをまとめる形式**です。外側を `|`、各パネル内のフレーム間を `/` で区切ります。2枚・3フレームなら次の並びです（P＝パネル、F＝フレーム、いずれも0始まり）。

```text
P0F0/P0F1/P0F2|P1F0/P1F1/P1F2
```

Resonite側ではまず出力全体を `|` で分割し、各要素をそのまま各パネルへ渡します。各パネルで `/` により分割し、同じフレーム番号のデータを取り出してください。各フレームは1bitなら69単位、5bitなら342単位です。全パネルのフレーム数と再生タイミングを揃えます。

32×32の出力は従来どおり1フレーム69単位です（`|` は入りません）。1bitの場合、フレーム数Nに対する1パネル分の長さは `70 × N − 1` 単位。パネル数Pを含めた総出力長は `70 × P × N − 1` 単位です。区切りの順序だけを変えるため、総文字列長は旧形式と同じです。見た目の文字数ではなくUTF-16 code unitsで数え、空白をトリミングしないでください。

「デコード」は文字列からパネル数とフレーム数を自動判定します。**パネルの並べ方は文字列に含まれません。** 候補が複数なら「復元する配置」で選びます。3枚なら96×32・32×96、4枚なら64×64・128×32・32×128などです。候補が1つの場合は自動決定します。このアプリでエンコードした直後は、指定済みの配置が選択されます。Resonite側でも配置は別途指定してください。編集キャンバスと同じサイズなら全ドットを比較し、異なるサイズなら復元だけ行います。編集グリッドは変更しません。

このアプリのデコーダーは、旧フレーム優先形式 `P0F0|P1F0/P0F1|P1F1` と、以前のパネル区切りなし64×64形式（276単位／フレーム）も自動判別して読み込めます。旧形式の場合は出力欄に表示します。新しいエンコード出力は常にパネル優先です。1枚だけ、または1フレームだけなら新旧で同じ文字列になります。空のパネル／フレーム、不正な長さ、パネル間で異なるフレーム数、旧形式でフレーム間のパネル数が異なる入力、配置できない枚数、Safe範囲外の文字、0でない未使用bitは拒否します。文字ごとの値の一覧は、復元プレビューに表示中の1フレームを確認できます。

## 5bitの明度・カラー

キャンバスの「ドットの出力」で、従来の **1bit・モノクロ**、**5bit・32段階の明度**、**5bit・固定32色（RGB221）** を選びます。初期値は互換性を保つ1bitです。上記の長さの表・69単位の説明は1bitについての仕様です。

- 明度は0が黒、31が白で、Resonite側の明度は `値 / 31` です。
- 固定32色は各ドットの5bitを `RRGGB` として使います。下位からB:1bit、G:2bit、R:2bitです。任意のRGB色はこの32色へ減色します。
- パレットまたは「描画する値」で0〜31を選んで描きます。5bitでは同じ場所を再度描いても同じ値を保持します。Shift＋描画／Space／Enterで値0に消去できます。文字・パターン・アニメーション・塗りつぶしにも選んだ値を使います。「32段階を並べる」で全32値を一覧できます。
- 画像は明度または固定32色に変換します。透明部分は黒に合成します。明度はsRGBの数値に `0.2126R + 0.7152G + 0.0722B` を適用して0〜31に丸めます。RGB221は各成分を最も近い段階に丸めます。
- 1bitから5bitへは0→0、1→31で全フレームを変換します。明度とカラーの切替は**値を変えずに表示方法だけ**を変更します。5bitから1bitへは明度50%で2値化し、中間値や色がある場合は変換前に確認します。5bitの反転は `31 − 値` です。

### 5bitの文字列とResonite側の復号

1パネルの1024ドットを、左上から横方向へrow-major順で保存します。各値は0〜31の整数です。15bitのSafe文字1つに3ドットを、下位5bitから順に格納します。行の末尾で区切らず、1024ドットを連続して処理します。

```text
packed = p0 + p1 * 32 + p2 * 1024
codeUnit = packed + 0x3000
```

1パネルの1フレームは **342 UTF-16 code units** です。最後の文字には1024個目のドットを下位5bitに格納し、上位10bitは0にします。使用範囲U+3000〜U+AFFF、パネル区切り `|`、フレーム区切り `/`、パネルの順序は1bitと共通です。

| 配置 | パネル数 | 5bitの静止画（1フレーム）の総出力長 |
| --- | ---: | ---: |
| 32×32 | 1 | 342 |
| 64×32 / 32×64 | 2 | 685 |
| 96×32 / 32×96 | 3 | 1028 |
| 64×64 / 128×32 | 4 | 1371 |
| 96×64 | 6 | 2057 |
| 最大16枚 | 16 | 5487 |

パネル数P、フレーム数Nの場合、1パネル分は `343 × N − 1` 単位、総出力長は `343 × P × N − 1` 単位です。空白に見えるU+3000をトリミングしないでください。

Resonite側では `|`、`/` の順に分割し、取り出した1パネル・1フレーム分の長さが69なら従来の1bit、342なら5bitとして読みます。5bitのドット座標 `(X,Y)` から取り出す式は以下です。文字・ドットの番号は0始まりです。

```text
panels = output.split("|")
framesForPanel = panels[panelIndex].split("/")
panelFrame = framesForPanel[frameIndex]
i = Y * 32 + X
packed = UTF16(panelFrame[floor(i / 3)]) - 0x3000
pixel = (packed >> ((i % 3) * 5)) & 31
# シフトが使えない場合: floor(packed / 2^((i % 3) * 5)) % 32

# 明度（0〜1）
brightness = pixel / 31

# RGB221（各0〜1）
R = floor(pixel / 8) / 3
G = (floor(pixel / 2) % 4) / 3
B = pixel % 2
```

**5bitを使うにはResonite側もこの復号に対応させる必要があります。** RGB値は表示用のsRGB成分として定義しています。受け側で線形色を扱う場合は色空間を合わせてください。明度かカラーかという表示方法、およびパネル配置は文字列には含めません。受け側にも同じ設定を指定します。アプリのデコード欄でも5bitの表示方法を選べます。1bitと5bitが混在するパネル／フレーム、不正な長さ、未使用bitが0でないデータは拒否します。

## 複数文字と文字アニメーション

「文字」タブで文章を入力します。改行を含め64文字まで入力でき、複数行もまとめて表示できます。文字サイズは「自動で収める」か6〜48pxの指定値を選びます。指定サイズが入らない場合は、小さくするか改行・スクロールを使ってください。

1文字ずつ改行した縦並びでは、文字同士が重ならない範囲で間隔を少し詰めます。空行を含む場合は通常の行間を使います。

- **静止画**：文章全体を現在のフレームに配置します。他のフレームは保持します。
- **上下左右のスクロール**：文章が画面外から入り、反対側へ抜けます。長文も途中で切り捨てず流します。自動サイズは読みやすさを優先し、移動方向に長くなることを許容します。
- **タイプライター**：最終的な配置を保ちながら、1文字ずつ表示します。
- **点滅**：文章全体が3回点滅します。
- **爆発／集合**：文章のドットが外へ散って消える、または集まって文章になります。
- **変形して現れる／1文字ずつ変形**：文章全体の出現と、従来の1文字ずつの切り替えを選べます。

動きに応じてフレーム数・移動量・停止時間を調整できます。アニメーション生成は全フレームを置き換え、再生間隔はフレーム欄の設定を使います。改行はEnter、生成はCtrl+Enter（macOSではCommand+Enter）でも実行できます。サンプルボタンから2行表示・日本語スクロール・爆発を試せます。

文字からの生成は最大240フレームです。上限を超える設定や表示できない文字サイズではエラーを表示し、既存のフレームを保持します。指定した配置全体で利用でき、パネルの境界をまたいで文章と動きがつながります。

## 自動テスト

## 縦画面プリセット（32×64）

「パターン」タブの「縦画面プリセット」から、ダンス・なわとび・ロケット上昇・泳ぐクラゲ・打ち上げ花火を選べます。全身の動きや上下移動を縦2枚で表現する、単色向けのアニメーションです。

選択するとキャンバスを32×64に切り替え、全フレームと再生間隔をプリセットの設定に置き換えます。再生ボタンで確認でき、生成後のドット編集も可能です。出力モードは維持し、5bitモードでは選択中の描画値を使います。出力は従来どおり「上パネルの全フレーム | 下パネルの全フレーム」です。
