# LCD32Encoder

Resonite向けに32×32のモノクロ画像・アニメーションをUTF-16 code unit列へ変換するWebアプリです。

## 実行

`index.html` をブラウザで開くだけで動作します。外部ライブラリ、ビルド、APIキーは不要です。

クラウド開発環境でHTTP経由の動作確認をする場合は、リポジトリのルートで以下を実行します。

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

ブラウザから `http://localhost:8000` を開きます。

## Codex cloud

1. Codex cloudでGitHubを接続し、このリポジトリへのアクセスを許可します。
2. このリポジトリを選択してクラウド環境を作成します。
3. セットアップスクリプトと環境変数の追加は不要です。
4. 環境と `main` ブランチを選び、開発タスクを開始します。

公式手順: https://learn.chatgpt.com/docs/cloud

## 変更時の確認

- ブラウザで画面を開き、コンソールエラーがないことを確認します。
- テストパターンをエンコードし、デコード結果が一致することを確認します。
- 複数フレームのアニメーションについても往復変換と再生を確認します。
- 画像読込や文字アニメーションを変更した場合は、その入力経路も確認します。

Safe形式は1フレーム69 UTF-16 code unitsで、複数フレームは `/` で区切ります。
