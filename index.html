32×32 LCD Encoder

32×32モノクロ画像を、Resoniteで扱えるUTF-16 code unit列へ変換します。外部ライブラリ不要・このHTMLをブラウザで開くだけで動作します。

ビット順: row-major（bitIndex = Y × 32 + X）。各行は X=0 が左端で、bit 0 が左端です。1行の前半16dotを1個目、後半16dotを2個目のushortに格納します。

UTF-16の注意: 画面の長さ表示・デコードはUnicodeの見た目の文字数ではなく、常にUTF-16 code unit数（JavaScriptの String.length）で行います。

アニメーション: Safe出力は frame1/frame2/... 形式です。各フレームは69 code units、区切り文字 / は1 code unitです。
