    使い方・エンコード仕様

    描く → 確認する → コピーする

    画像を読み込むか、グリッドをクリック・ドラッグして編集します。キーボードではグリッドにTabで移動し、矢印キーでドットを選び、SpaceまたはEnterで切り替えられます。

    「エンコード」で全フレームを文字列に変換し、「コピー」でResoniteへ持ち出せます。変換時にすべてのドットが正しく復元できるか自動で検証します。

    「文字」では複数文字・改行をまとめて表示できます。「静止画」は現在のフレームに配置し、文字サイズは自動調整か指定サイズを選べます。

    動きは上下左右のスクロール、タイプライター、点滅、爆発、集合、変形から選べます。従来の「1文字ずつ変形」も使えます。アニメーション生成は全フレームを置き換えます。移動量や停止フレームを設定し、再生速度はフレーム欄の「間隔」で調整します。

    文字は改行を含め64文字、生成は240フレームまでです。スクロールは画面の外から入り、反対側へ抜けます。長い文章は移動量を増やすとフレーム数を減らせます。Ctrl+Enterでも生成できます。

    「デコード」はパネル数を自動判定して右側のプレビューに復元します。並べ方が複数ある場合は「復元する配置」で選びます。編集キャンバスと同じサイズ・表示方法の場合は全フレームを比較します。編集グリッドには反映しません。

    Safe形式の仕様

    「ドットの出力」で1bit・32段階の明度・固定32色を選びます。5bitは値0〜31を保存し、明度は値 / 31（0＝黒、31＝白）です。描画パレットは文字・パターン・塗りつぶしにも使えます。Shiftを押しながら描くと値0で消去します。

    固定32色はRGB221です。Resonite側のRGB（0〜1）はR = floor(値 / 8) / 3、G = floor(値 / 2) % 4 / 3、B = 値 % 2。明度とカラーは同じ値の表示方法で、切り替えても値は変わりません。画像は選択した方法で減色し、透明部分を黒に合成します。

    サイズは幅×高さです。「パネルの枚数で指定」で横・縦それぞれ1〜8枚、合計16枚まで配置できます。96×32は横3×縦1枚、96×64は横3×縦2枚です。各パネルは32×32のSafe形式で、回転や反転は行いません。

    ピクセルはパネル内の左上から横方向に並ぶrow-major順です。i = Y × 32 + X。1bitは15ドットずつ格納して69単位。最後は4bitで、残り11bitは0です。5bitは3ドットずつ格納して342単位。最後は1ドットの5bitで、残り10bitは0です。行の途中には0埋めしません。

    codeUnit = value + 0x3000。使用範囲はU+3000–U+AFFFで、サロゲートや制御文字を含みません。復号時はToUTF16(character) - 0x3000で値を戻します。

    1パネル・1フレームは1bitで69単位、5bitで342単位です。各パネルの全フレームを/でつなぎ、そのパネルごとの文字列を|でつなぎます。例：P0F0/P0F1|P1F0/P1F1（P＝パネル、F＝フレーム、0始まり）。パネルの並び順は左上から右へ、次に下の段へです。

    パネル数P・フレーム数Nに対する総出力長は、1bitで70 × P × N − 1、5bitで343 × P × N − 1単位です。各パネル内の全フレーム数を揃えます。未使用bitの0埋めは各パネルの各フレームごとに入ります。

    5bitの1文字はp0 + p1 × 32 + p2 × 1024 + 0x3000です。復元はパネルの1フレームからfloor(i / 3)番目の文字を取り出して0x3000を引き、(値 >> ((i % 3) × 5)) & 31でドット値を取り出します。1bit / 5bitは1パネル・1フレームの長さで判定できますが、明度 / カラーの指定は別途共有してください。5bit出力を使うにはResonite側にもこの復号処理が必要です。

    Resonite側では先に|でパネルごとに分割して渡し、各パネルで/によりフレームを分割します。全パネルで同じフレーム番号と再生タイミングを使います。枚数は自動判定できますが、配置は別途指定します。たとえば4枚なら64×64・128×32・32×128が考えられます。

    以前のフレーム優先形式P0F0|P1F0/P0F1|P1F1も自動判別して復元できます。さらに以前の区切りなし276単位の文字列は64×64として読み込みます。新しいエンコード出力はパネル優先です。1パネルだけ、または1フレームだけなら新旧の文字列は同じです。

    サイズ変更は全フレームに適用し、既存の絵を左上に保持します。範囲外の絵が切れる場合は確認が表示されます。サンプルと文字は縦横比を保って中央に配置します。

    長さは見た目の文字数ではなく、JavaScriptのString.lengthで数えます。文字アニメーションの入力はUnicode文字単位で扱います。

    左上32×32だけを残しますか？

    全フレームの右半分・下半分にあるドットが削除されます。この操作は元に戻せません。

    1bitに変換しますか？

    全フレームを明度50%で0 / 1に変換します。中間の明度と色は失われます。
